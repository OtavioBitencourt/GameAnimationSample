Overview

Auto Setup provides fully automated shader and skeleton assignments for Character Creator (CC) and iClone characters in Unreal Engine. It streamlines the entire import pipeline by generating Blueprints for material parameters, configuring texture workflows, preparing model and Control Rig setups, and applying Live Link settings for real-time performance integration.

Supported Versions

Installation Guide

  1. Please ensure that your Unreal Engine version is supported.
  2. Download the Auto Setup plugin package.
  3. Copy the Plugins folder into your Unreal project directory.
    Example: YourProject/Plugins
  4. Copy the Content folder into your project directory.
    Example: YourProject/Content

Important Notice: Update & Removal

  1. Open your Unreal Engine project.
  2. Remove CC character materials used by Auto Setup from the Content Browser (depends on the character you used).
  3. Delete the CC_Shader folder under the Content directory in Unreal.
  4. Close Unreal Engine.
  5. Delete the Plugins folder from your project directory.
  6. Reinstall the latest version by following the Installation Guide and reassign Auto Setup to your characters.
